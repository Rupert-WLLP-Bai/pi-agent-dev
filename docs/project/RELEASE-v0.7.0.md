## 已知边界

- 当前没有身份认证、RBAC、SSO或多租户；`X-Operator`只记录归属，部署入口需限制访问范围。
- 单进程dispatcher/SSE仍是运行边界；不宣称支持多副本。
- Web单块1614.71kB，有Vite大块警告；后续按M2体验/性能任务处理。
- 行/函数覆盖率不能代替分支覆盖率或真实模型准确率；未宣称业务效率、成本或生产规模收益。
- 数据库备份不复制对象存储字节；完整灾备仍需独立对象存储备份。

回退应切换到已知提交或镜像并保留数据库及对象卷；不移动旧Tag、不删除合同原件、不回滚已审阅数据。认证重新实施与后续里程碑按任务板安排。
