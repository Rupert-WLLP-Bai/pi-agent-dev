## 2. 回滚策略（按变更类型）

| 变更 | 回滚动作 | 数据兼容 |

| 影子功能 | `DECISION_MODE=off`，停 shadow worker | 新表与历史影子记录保留；不做破坏性 down |
| 访问门 | 已延期（2026-10-17）：当前代码无认证实现，无可回滚/无待回滚动作；重新排期实现时以 `docs/runbook/access-control.md` 的最低要求为验收 | 无数据影响；历史口令/会话实现已移除，`API_ACCESS_TOKEN` 变量无效果 |

| 迁移 | 只做增量；失败停在该批次 | 旧列可空，不倒配历史 |

## 4. 运营视角的限制（对外口径必须包含）

- 单实例部署；进程内 dispatcher/SSE/Pi session；多副本需要重新评估队列与事件机制（README"能力边界"已声明）。
- **认证已延期（2026-10-17 用户指示）**：当前无登录/Bearer/session 强制，也没有 SSO/RBAC/多租户。访问控制依赖部署侧网络隔离；对外口径必须写明"系统自身无认证"，不得暗示有访问门。
- 影子输出是建议，不是结论；未校准即标记，不进自动路由。
- 性能数字仅为历史实测样本（审计约 62 s；OCR 396 s 样本），不作吞吐承诺。
